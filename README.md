A deterministic Python program (stdlib only) that writes one funny, painfully honest comment line — the kind a developer leaves above fragile production code nobody dares to touch — to `/output/entry.txt`. The line names a real, recognisable failure: two bugs that cancel each other out, so fixing either one breaks everything.

## Run it

```sh
python3 main.py
```
